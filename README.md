# Attack on Titan – Fan Site

Site temático e responsivo sobre o anime *Attack on Titan*, criado como projeto de estudo de desenvolvimento front-end.

🔗 **Acesse o site:** https://pedrinph1.github.io/attack-on-titan/

## Funcionalidades

- **Layout responsivo**: se adapta a computador, tablet e celular (CSS Grid, Flexbox e media queries).
- **Menu para celular**: botão que abre e fecha o menu, com animação do ícone.
- **Menu que acompanha a rolagem**: o item da seção visível fica destacado (IntersectionObserver).
- **Janela de detalhes dos personagens**: ao clicar em um card, abre uma janela com nome, função e descrição (elemento `<dialog>`).
- **Busca de personagens**: filtra os cards enquanto você digita, ignorando acentos e maiúsculas.
- **"Ver mais"**: mostra e esconde conteúdo extra no card de História.
- **Fundo fixo com efeito de profundidade** nas seções abaixo do banner.

## Tecnologias

- HTML5 semântico (`header`, `main`, `section`, `article`, `footer`, `dialog`)
- CSS3 (variáveis, Grid, Flexbox, `clamp()`, transições e media queries)
- JavaScript puro, sem bibliotecas

## Como rodar no computador

1. Baixe ou clone este repositório.
2. Abra a pasta no VS Code.
3. Use a extensão **Live Server** (botão "Go Live") ou abra o `index.html` no navegador.
